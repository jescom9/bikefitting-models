# bikefitting.fit model assets

Public, versioned model downloads for browser-side bike fitting. No user videos, measurements, private application code or credentials are stored here.

RTMPose checkpoints are the unchanged OpenMMLab HALPE26 models at 256×192 (S) or 384×288 (M/L/X). Binary parts are concatenated in manifest order; SHA-256 hashes verify every part and the original file. Models run on the visitor's device.

Upstream: https://github.com/open-mmlab/mmpose/tree/main/projects/rtmpose
Checkpoints: https://download.openmmlab.com/mmpose/v1/projects/rtmposev1/onnx_sdk/
